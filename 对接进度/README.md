## 更新方式

1. 在自己的 GitHub 用户名目录下保存 `YYYY-MM-DD.md`；同一天补充写入同一份记录。
2. 记录环境与代码版本、做了什么、实际验证结果、仍存在的问题、下一步及需要其他成员配合的事项。
3. 更新上面的索引，让组员打开本文件夹就能找到最新进展。
4. 将“本地完成”“已上传”“其他机器复现”分别说明。虚拟检查点、实体门、视觉导航分别验收；历史测试结果不能当作后续版本已通过。

这里保存进度和可公开的验证摘要。代码改动放回对应源码目录；文档中的待办事项不等于已经完成。仓库公开，请勿放入密码、密钥、私人联系方式或虚拟机文件。
