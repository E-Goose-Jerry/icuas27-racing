## 测量证据及边界

- [门模型测量.json](门模型测量.json) 保存 7 个门洞中心、净宽/净高、无符号法线角和源文件 SHA-256。
- [inspect-gate-geometry.py](inspect-gate-geometry.py) 是只读诊断脚本；不修改地图、不启动仿真、不生成可开飞赛道。
- 本地 vendor 文件与 Ubuntu 运行路径中的 world、model.sdf、OBJ、STL 四个文件校验值一致。SDF 没有给门模型额外平移、旋转或缩放。
- 测量使用三角面求交：每扇门在两个方向各检查 5 个截面。`Cube` 至 `Cube.005` 的显示 OBJ 与碰撞 STL 一致，最大求交差约 4.3e-7 米；`Cube.006` 的整个包围区域都没有碰撞 STL 三角面的包围盒与之相交。
- 当前模型外框宽约 0.6 米、边框厚约 0.05 米，和 0.5 米净开口一起呈现文档规格的一半；这提示需要核对版本或建模比例，但不能据此断定缩放来源，更不能把官方规格改成 0.5 米。

以上是当前 Docker 脚本的默认目录；如实际目录不同，按其 `LUS_ROOT` 和 `CF_DIR` 调整。复现测量时把 `--resources` 指向实际 `laser_gazebo_resources` 目录：

```bash
python3 inspect-gate-geometry.py \
  --resources /opt/git/laser_uav_system/ros_packages/laser_gazebo_resources \
  --output /tmp/crazyrun-gates.json
```

脚本专门用于本次固定版本的直立门框；遇到额外位姿/缩放或不支持的网格会报错，不能把脚本报错等同于组员模型有问题。
